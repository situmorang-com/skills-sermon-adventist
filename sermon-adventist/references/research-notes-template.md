# Research Notes Template

This is the exact structure for the `research-notes.md` document the `sermon-adventist` skill produces in Step 2 (before brainstorm). Use this as the literal template — same headers, same order, same depth targets.

---

## Filename and header

Save as `research-notes.md` (or `catatan-penelitian.md` for Indonesian sermons).

Top of file:

```markdown
# Research Notes: [Passage Reference]

*Prepared for: [audience if given]*
*Translation: KJV (English) / Terjemahan Baru (Indonesian)*
*Date: [date]*

This is research, not the sermon. Read it. Pray over it. Use what helps. Set aside what doesn't.
```

## Closing line

End the file with:

```markdown
---

*Research complete. EGW citations verified via egwwritings.org where possible; uncertain quotes paraphrased without quote marks per the foundation's Tier 1/2/3 policy. Commentary content paraphrased from named sources — verify direct quotes in your copy before relying on them in the pulpit.*
```

---

## Length and tone

- **Total target:** 1,500-2,500 words for a typical 30-minute sermon. Longer for dense passages (Daniel 8, Romans 8); shorter for narrative texts.
- **Tone:** Pastoral but substantive. Not a seminary paper. Not a devotional. The preacher should be able to read it in 10-15 minutes and come away with both clarity on the text and material to preach from.
- **Honesty about gaps:** If you don't know what a commentary says, say so. If an EGW quote isn't verifiable, paraphrase. Never fabricate to make the document look more complete.
