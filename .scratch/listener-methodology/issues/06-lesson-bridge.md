# The lesson bridge: orienting a class that did not read

Type: grilling
Status: open

## Question

Q12 chose derivation over memory: the guide has no continuity of *people* — a different
congregation each week — but the quarterly is globally sequential, so continuity of *content*
is real. Every Adventist studied last week's lesson somewhere.

So the opening can orient an unprepared class by saying where the church has been, fetched from
lesson N-1 via the same Adventech API rather than remembered from a previous guide.

Settle:

- What the bridge actually says. One sentence? Where does it sit in the 0–3 opening, which is
  already spoken for by the hook and the week's claim in one sentence?
- Whether it competes with the hook. The opening's job is that somebody other than the teacher
  speaks by minute two; a bridge is teacher talk and risks eating that.
- Lesson 1 of a quarter has no predecessor. What happens then?
- Whether this is worth its minute at all, given it is orientation rather than accountability —
  the weaker of the two things it was originally meant to do.
